# Interview English

Тренажёр технических собеседований и лайв-кодинга на английском. Идея: 10 минут в день, без зубрёжки и без чувства вины.

## Как устроено

- **Ежедневная миссия (Today).** Разминка из карточек, одно главное задание, разбор двух главных ошибок. Ошибки сразу становятся карточками.
- **Сюжет.** Вы «проходите отбор» в вымышленную компанию: рекрутер → техническое интервью → лайв-кодинг → системный дизайн → финал с решением «hire / no hire». Потом следующая компания. Офферы копятся.
- **7 форматов**, чтобы не было скучно: Blitz (30 секунд на вопрос), Deep question, Approach only (объяснить решение без кода), Mini live coding, Shadowing (повторять сильный ответ по предложениям), My story (история по STAR), Final interview. Формат не повторяется два дня подряд. Кнопка «Boring, swap it» убирает формат на неделю.
- **Мягкая мотивация.** Цель 4 дня в неделю, пропуск нормален. После перерыва 4+ дней миссия лёгкая. Есть уровни 4 навыков: Fluency, Clarity, Algorithms, Vocabulary.
- **Карточки с интервальным повторением** (1, 3, 7, 16, 35, 80 дней): ваши ошибки, алгоритмические паттерны, фразы.
- **Свободная практика:** Mock interview (20 вопросов), Live coding (6 задач, тесты в воркере), Phrasebook, Progress.
- **Обратная связь без ключа:** слова-паразиты, темп, типичные ошибки русскоязычных («I am agree», «depends of», «3 years experience»), покрытие ключевых идей, чек-лист объяснения.
- **AI-интервьюер:** если на сервере задан `ANTHROPIC_API_KEY`, ответы проверяет Claude: отдельно английский и суть, исправления, «как сказать лучше», уточняющий вопрос.

## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm run dev                              # http://localhost:5173
npm run build && npm start               # продакшен
```

### AI-интервьюер

1. Возьмите ключ на https://console.anthropic.com/settings/keys.
2. В папке проекта создайте файл `.env` (можно скопировать `.env.example`; файлы с точкой в начале скрыты в Finder и Проводнике).
3. Впишите в него одну строку: `ANTHROPIC_API_KEY=sk-ant-...`
4. Перезапустите `npm run dev`. В левом нижнем углу появится «AI interviewer on».
5. Проверка, что ключ работает: `npm run check:ai`.

Файл `.env` в `.gitignore`, в репозиторий он не попадёт.

## Проверки

```bash
npm run typecheck   # TypeScript
npm test            # юнит-тесты логики и контента (эталонные решения прогоняются через тесты задач)
npm run e2e         # настоящий браузер + настоящий сервер: все форматы, миссия, сюжет, телефон, тёмная тема
npm run check:ai    # реальный запрос к Claude API (нужен ANTHROPIC_API_KEY)
```

Голосовой ввод работает в Chrome и Edge. В e2e ответы вводятся текстом, потому что распознавание речи без экрана не работает.

## Стек

React 19 + TypeScript + Vite, CodeMirror 6, Express 5 (один сервер отдаёт API и фронтенд), Anthropic SDK (`claude-opus-5-5`, structured outputs), Web Speech API, lucide-react, шрифты Inter и JetBrains Mono локально. Прогресс хранится в localStorage браузера.

## Структура

src/pages/         Экраны
tests/e2e.mjs      Браузерный тест
scripts/check-ai.ts  Проверка настоящего AI
